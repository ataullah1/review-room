# Self-hosted fonts

Unmodified Latin variable WOFF2 subsets downloaded from the official Google Fonts CSS API on 18 October 2026. DM Sans and Manrope retain their existing product family names. Both are distributed under the SIL Open Font License 1.1; the complete copyright/license notices are included alongside the files. Other scripts use the existing system fallback fonts.

Sources: https://fonts.google.com/specimen/DM+Sans and https://fonts.google.com/specimen/Manrope. Upstream license notices: https://github.com/google/fonts/tree/main/ofl/dmsans and https://github.com/google/fonts/tree/main/ofl/manrope.

These files are served from the application origin. Neither visitors nor production builds need to contact Google to load them. No tracking or new branding assets were added.
